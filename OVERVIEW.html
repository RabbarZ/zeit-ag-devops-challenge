How it works

  1. Orient. Read docs/, skim the Terraform and compose files.
  2. Answer A1–C6 briefly in SOLUTION.md. Bullets are enough.
  3. Implement three changes: A3, B1 and one C question.
  4. Reflect in R1–R6: your work, the AI, and agentic delivery.
  5. Hand in before the agreed deadline with npm run handin.
  6. Debrief: 15-minute walkthrough, then questions. No AI assistant.

The system at a glance

One app VM per environment behind Caddy, a shared observability VM and a shared control VM. Each environment has its own network, PostgreSQL server and Key Vault.

Read in this order

  1. docs/product.md: customers, users, recovery targets
  2. docs/architecture.md: how it is hosted today
  3. docs/incidents.md: six condensed incidents
  4. Skim infra/environments/production/main.tf, infra/modules/app-environment/main.tf, infra/modules/vm/main.tf
  5. Skim runtime/app/compose.yml and runtime/observability/compose.yml

You do not need to read every file. Some details in the pack are things a generic answer gets wrong: check claims against the files.

Commands

Local checks (optional, no Azure)

# mocked Terraform plan for staging
npm run infra.plan
# validate and plan-only tests, all four roots
npm run infra.verify
# compose check, terraform fmt and validate
npm run validate

Need Terraform 1.11.4 or newer. A skipped check is not a pass: report what you ran.

Optional local stack (Docker)

# build, start and wait for both tenants
npm start
# k6 traffic for 2 minutes
npm run load
# stop one service and watch what happens
npm run stop -- postgres
# stop everything and delete the volumes
npm stop

Grafana on localhost:30000, Prometheus on localhost:30001. Its time counts toward the recommended 2 hours.

AI and ground rules

Do

  • Use AI assistants and coding agents fully: reading, drafting, coding, running the local checks.
  • Check every AI claim against the files, and note what it got wrong in R4.
  • Name tools and what you used them for under “Tools and AI used”.
  • Mark untested or partial work honestly; a skipped check is not a pass.
  • Ask the interviewer about the task or setup whenever something is unclear.

Don’t

  • Run a cloud apply, contact the fictional hosts or add credentials, and don’t let an agent do so.
  • Invent facts beyond docs/: write assumptions down instead.
  • Add a GitHub workflow or an apply/destroy command.
  • Use an AI assistant in the debrief: you explain every line yourself.
  • Share this pack or your answer outside the interview.
